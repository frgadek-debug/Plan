# Plan obowiązków

Aplikacja do pilnowania planu dnia i nauki na 6 miesięcy: bloki dnia z timerem, plan Pythona (78 lekcji), cele i statystyki.

Działa w przeglądarce i jako aplikacja na telefonie (PWA), także bez internetu. Dane zapisują się na urządzeniu; kopię zapasową robisz w zakładce Ustawienia.

**Instalacja na telefonie:** otwórz stronę z GitHub Pages, a potem na Androidzie w Chrome wybierz menu ⋮ → „Zainstaluj aplikację”, a na iPhonie w Safari „Udostępnij” → „Do ekranu początkowego”.
